# Post ↔ code notes

One short note per blog post, linking the narrative (the published post) to the code path in
this repo that implements it. This is the *reverse* of the table in the top-level README: a
reader who arrives at the code via GitHub search lands here and finds the story behind it.

> Add a file per post as it publishes, e.g. `a1-eleven-second-hello.md`, containing: the post
> link, the directory it backs, and any "run it yourself" notes that don't belong in the code
> README.
